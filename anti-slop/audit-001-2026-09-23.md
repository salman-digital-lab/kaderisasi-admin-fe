# Antislop audit 001 — participant answer columns

Scope: the new answer columns and column controls on activity participant and club registration lists.

## Findings

No findings in the changed UI.

## Evidence

- At 1440px and 390px, the club list shows answer labels and values in the existing table or expanded mobile card. The activity list does the same, including an inactive attached form.
- Both lists retain the established Ant Design controls, spacing, typography, and responsive list pattern. No new decoration, marketing copy, visual assets, or navigation was added.
- Question columns use 240px widths, wrap long text, and allow horizontal table scrolling. Mobile cards keep extra answers in their existing expandable details.
- The new column controls work with keyboard-accessible checkboxes and buttons; hide, reset, and reload were exercised in browser checks.
- Missing answers display “Tidak diisi”; file answers reuse the existing authenticated download control with its loading and error states.

Validation: `npm test` (177 tests), `npm run lint`, `npm run build`, and the 1440px/390px Playwright checks for activity and club lists passed.
